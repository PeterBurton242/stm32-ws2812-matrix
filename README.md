# STM32 Addressable LED Matrix

An embedded C driver for controlling WS2812 addressable LEDs using an STM32 microcontroller, hardware timers, PWM, and DMA.

## Overview

This project implements a driver for controlling individually addressable WS2812 LEDs with an STM32L476 microcontroller.

Because WS2812 LEDs use a timing-sensitive single-wire communication protocol, the driver uses an STM32 hardware timer and PWM to generate the required signal. DMA transfers the encoded LED data to the timer peripheral, reducing the need for continuous CPU intervention during transmission.

## Hardware

* STM32 NUCLEO-L476RG development board
* STM32L476RG microcontroller
* WS2812 addressable LEDs
* 5 V LED power supply

## Technologies

* Embedded C
* STM32
* STM32 HAL
* STM32CubeIDE
* PWM
* DMA
* Hardware Timers

## Implementation

Each LED receives 24 bits of color data representing its red, green, and blue values. The driver converts the requested pixel colors into a buffer containing PWM duty-cycle values corresponding to digital `0` and `1` bits.

The STM32 timer generates the precisely timed PWM output required by the LEDs. DMA transfers the prepared buffer to the timer, allowing the complete LED data stream to be generated by hardware rather than manually toggling a GPIO from software.

The driver provides functionality for setting individual pixel colors and transmitting the completed LED buffer to the LED chain.

## Key Features

* Individual RGB pixel control
* WS2812 signal generation using hardware PWM
* DMA-based data transmission
* Timing-sensitive LED protocol implemented in embedded C
* Hardware timer configuration on STM32

## How It Works

1. RGB values are converted into the WS2812 24-bit color format.
2. Each bit is translated into the appropriate PWM duty cycle.
3. The encoded values are stored in a transmission buffer.
4. DMA transfers the buffer to the STM32 timer.
5. The timer generates the waveform required by the LED chain.

This approach offloads most of the timing-sensitive signal generation to the STM32's hardware peripherals.
